# stock_analysis_web_application

# 1) Goal of the System

Pulls stock data via Yahoo Finance.
Analyzes historical and real-time data.
Recommends whether to buy, sell, or hold each stock.
Explain the recommendation and explaination of the stock.
Displays key metrics and charts (price trends, RSI, MACD).

# 2) Images of the web application

The user are enter the stock symbol and time frame .
